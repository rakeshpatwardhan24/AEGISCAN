# AEGISCAN

## Intelligent CAN Cybersecurity for EV, BMS, Aerospace & UAV Systems

AEGISCAN is a cybersecurity project focused on monitoring and analyzing
Controller Area Network (CAN) communication in safety-critical systems.

The project aims to identify abnormal or potentially malicious CAN traffic
and provide appropriate security alerts.

## Project Overview

Modern systems such as Electric Vehicles (EVs), Battery Management Systems
(BMS), aerospace systems, and UAVs rely on CAN-based communication.

However, traditional CAN communication has limited built-in cybersecurity
mechanisms. This creates opportunities for attacks such as message injection,
replay attacks, and denial-of-service attacks.

AEGISCAN aims to develop an intelligent monitoring and detection system for
identifying suspicious CAN communication.

## Objectives

- Understand CAN bus communication and cybersecurity.
- Collect and analyze CAN traffic.
- Identify abnormal CAN communication patterns.
- Develop methods for detecting suspicious traffic.
- Generate security alerts and maintain event logs.
- Test and validate the detection system.
